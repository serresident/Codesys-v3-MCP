# Оптимизация сетевого транспорта и архитектуры CODESYS / Abak.IDE Automation Bridge

* **Author:** ess2
* **Date:** 2026-11-09

## Overview

Документ описывает концепцию модернизации сетевого уровня, алгоритмов обнаружения портов и разделения зон ответственности для комплекса автоматизации `abak-ide-bridge`. Цель — устранить длительные блокирующие задержки (падение с 75–150 секунд до ≤ 1.5 секунд при оффлайн-сервере), ликвидировать дублирование сетевого кода между CLI и MCP-сервером, синхронизировать пул портов и предоставить ИИ-агенту контекстные подсказки при сохранении полной свободы действий.

## Analysis

Комплексный аудит по 7 специализированным линзам (Contrarian/YAGNI, Архитектура, Эргономика, Диагностика, Скрытый техдолг, Модульность и ТРИЗ) выявил следующие ключевые аспекты:

1. **Проблема синхронного перебора портов (SYN Drop в LAN)**:
   При сетевой работе с соседней инженерной станцией, если служба выключена или закрыта брандмауэром Windows, стек TCP сбрасывает SYN-пакеты. Последовательный перебор 5 портов с таймаутом 15–30 секунд приводил к глухому зависанию агента на 1.5–2.5 минуты. Решение — двухступенчатый адаптивный опрос: сверхбыстрая проверка последнего активного кэшированного порта (150–400 мс), а при его недоступности — параллельный discovery-probe по всему пулу портов через пул потоков с жестким общим дедлайном в 1.5 секунды.
2. **Асимметрия пула портов**:
   Сервер слушает список `[11888, 11889, 11890, 12888]`, а клиенты опрашивают `[11888, 11889, 11890, 11891, 12888]`. Порт 11891 является «призрачным» в клиентах. Требуется строгая синхронизация пула в обоих слоях.
3. **Ликвидация дублирования кода без раздувания зависимостей**:
   Сетевой код скопирован между `client/abak_bridge_client.py` и `mcp_server/abak_mcp_server.py`. Выделяется легковесный модуль `common/transport.py` на базе исключительно стандартной библиотеки Python (`socket`, `concurrent.futures`, `json`). Это гарантирует работу без внешних pip-зависимостей (`requests`, `aiohttp`) и сохраняет сервер `codesys_bridge_server.py` полностью автономным для IronPython 2.7.
4. **Информативная диагностика CLR без подавления ошибок**:
   Блок `clr.AddReference` в сервере заменяется на структурированное логирование загруженных сборок (`System.Windows.Forms`, `System`, `System.Xml`) с выводом разрядности процесса (32/64-bit) и версии IronPython, исключая недиагностируемые падения при импорте таймеров.
5. **Мягкие направляющие для ИИ (Paved-Road Docstrings)**:
   Вместо жестких ограничений и блокировок, docstrings MCP-инструментов обогащаются эвристиками: для логики и POU рекомендуется путь через PLCOpen XML (`abak_import_plcopen_xml` / `abak_export_sources`), а для аппаратного дерева и I/O Mapping — `abak_map_io` и `abak_exec_python`.

## Goals vs. Non-Goals

* **In-Scope Goals:**
  * Сокращение времени обнаружения недоступного хоста с 75–150 с до ≤ 1.5 с за счет concurrent probe.
  * Создание единого модуля `common/transport.py` и перевод на него CLI-клиента и MCP-сервера с сохранением обратной совместимости API.
  * Синхронизация пула портов `[11888, 11889, 11890, 11891, 12888]` на сервере и клиентах.
  * Информативное логирование среды CLR при старте сервера в Abak.IDE.
  * Актуализация описаний MCP-инструментов для минимизации ошибок выбора инструментов LLM.

* **Out-of-Scope Non-Goals:**
  * Внедрение асинхронных тяжелых сетевых библиотек (`asyncio`, `aiohttp`, `httpx`), нарушающих совместимость со скриптами без venv.
  * Жесткая программная блокировка выполнения скриптов изменения POU через `abak_exec_python` (свобода агента сохраняется в полном объеме).
  * Изменение внутренней потоковой модели таймера `System.Windows.Forms.Timer` в сервере.

## Alternatives Weighed

* **Последовательный перебор портов с уменьшенным таймаутом**: Отклонено, так как при физически отключенном кабеле или блокировке файрволом 5 последовательных проверок даже по 1 с суммарно дают 5 с задержки вместо субсекундного параллельного отклика.
* **Внедрение gRPC или ZeroMQ**: Отклонено из-за ограничений встроенной среды IronPython 2.7 в Abak.IDE/CODESYS, где компиляция нативных C-библиотек невозможна.
* **Принудительный запрет `exec` для POU**: Отклонено по требованию пользователя («оставить свободу агенту на нештатные случаи»).
