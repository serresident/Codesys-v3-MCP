## 1. Типовая сетевая топология
| Узел / Оборудование | Типовой IP | Роль / Назначение | Доступные порты / Сервисы |
|---------------------|------------|-------------------|----------------------------|
| **Инженерная станция (ПК с Abak.IDE)** | `192.168.1.100` | Хост со средой CODESYS V3.5 / Abak.IDE. Запуск `server/codesys_bridge_server.py`. | `11888` (HTTP/JSON Bridge), `1217` (CODESYS Gateway), `11740` (Codesys V3 Runtime) |
| **Целевой ПЛК** | `192.168.1.200` | Контроллер автоматизации / PLC. | `502` (Modbus TCP), `1217` (Gateway), `11740` (Runtime), `80/443` (Web) |

| **Сервер БД / Телеметрии** | `192.168.1.150` | Сбор технологической телеметрии. | `8089` (UDP Line Protocol / InfluxDB) |

## 2. Ключевые технологические особенности CODESYS ScriptEngine
1. **Интерпретатор IronPython 2.7**:
   - Внутри Abak.IDE / CODESYS выполняется IronPython 2.7 (.NET Framework).
   - Поддерживаются вызовы стандартной библиотеки Python 2.7 и всех сборок Microsoft .NET (`System`, `System.Net`, `System.Windows.Forms`).
   - Синтаксис `print` — как оператор или функция Python 2.
   - При работе с локализованным текстом в ST-файлах обязательна явная кодировка UTF-8.
2. **Неблокирующая многопоточность через Windows Forms Timer**:
   - Обычный `while True: time.sleep(1)` в ScriptEngine **замораживает основной GUI-поток CODESYS**.
   - Решение: использование объекта `.NET Windows.Forms.Timer` с интервалом `100 мс`. Таймер обрабатывает тики в UI-потоке, опрашивая `socket.Poll` или `TcpListener.Pending()`. Если входящего запроса нет — немедленно передает управление циклу отрисовки Windows (`Application.DoEvents()`).
3. **Обновление открытых вкладок редактора**:
   - При программной замене текста (`obj.textual_implementation.replace(...)`) данные мгновенно сохраняются в объектной модели проекта на диске.
   - Однако графический буфер открытых в данный момент вкладок редактора в Abak.IDE не обновляется на лету: пользователю необходимо закрыть вкладку (без сохранения) и открыть заново двойным кликом из дерева.
4. **Соотнесение каналов ввода/вывода (I/O Mapping)**:
   - Привязка переменных к аппаратным каналам модуля выполняется через `p.io_mapping.variable = 'Application.GVL.myVar'`.
   - **Важно**: в `io_mapping.variable` допустимы только строгие скалярные идентификаторы; индексы массивов типа `[0]` отклоняются драйвером CODESYS на уровне ядра.

## 3. Безопасность и отказоустойчивость
- Сервер моста слушает только запросы `GET` и `POST` с телом JSON.
- Любое необработанное исключение изолируется внутри блока `try..except` и возвращается в JSON-ответе с трейсбеком, не нарушая работу самой среды Abak.IDE.
- При перезапуске слушателя сокет не вызывает конфликт портов благодаря защищенной обработке `System.Net.Sockets.SocketException`.
